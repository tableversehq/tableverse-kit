---
title: "Create your project"
description: "Scaffold a game with a working engine and frontend."
---

Create a project and install its dependencies:

```bash
npm create tableverse token-race
cd token-race
npm install
```

The target directory must be empty. The scaffolder uses the directory name as the package and game name.

## Project structure

```text
token-race/
├── engine/
│   ├── src/
│   │   ├── commands.ts
│   │   ├── events.ts
│   │   ├── game.ts
│   │   └── state.ts
├── client/
│   └── src/main.ts
├── package.json
├── package-lock.json
└── tableverse.config.ts
```

The scaffold already contains a playable scoring command and a plain TypeScript frontend. Start it before changing anything:

```bash
npm run dev
```

Open the URL printed by Vite, usually `http://localhost:5173`, and click **Score a point**. The displayed view should update.

<Tip>
  Edit files under `engine/src` for rules. Edit files under `client/src` for the interface.
</Tip>
