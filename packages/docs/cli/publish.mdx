---
title: "tvk upload"
description: "Upload your project source and start a Tableverse build."
---

`tvk upload` packages the workspace containing `tableverse.config.ts`, uploads it, and starts a Tableverse build.

Tableverse uses the engine and frontend source directories in your config to build the uploaded workspace.

## Before the first upload

Make sure your config has a `publish` block and your project has a lockfile:

```bash
npm run typecheck
npx tvk validate
npx tvk login
```

Check the active account at any time:

```bash
npx tvk whoami
```

## Upload

```bash
npx tvk upload
```

For an unlinked project, the CLI asks you to create a game or choose one already in your account. It then writes the selected ID to:

```text
.tableverse/game.json
```

Future uploads use that link. The CLI prints the target game name and ID before packaging.

<Warning>
  A copied project may retain `.tableverse/game.json`. Verify that the printed target is the game you intend to update.
</Warning>

## What gets uploaded

The CLI uploads the full project root: the directory containing `tableverse.config.ts`. This keeps the root `package.json`, lockfile, workspace packages, and shared files together.

It excludes:

- `node_modules`, `.git`, and `.tableverse` directories.
- The frontend build output because Tableverse rebuilds it.
- Local `.env` files such as `.env.local`.
- Symbolic links.

Files such as `.env.example` remain included. Packaging stops if it finds common private-key or credential files, including `.npmrc`, `.pem`, and `.key` files.

The project root must contain `package-lock.json`. The engine and frontend use the same npm workspace installation.

## Follow the deployment

After the project source uploads, the CLI starts the build and prints a dashboard URL. In an interactive terminal, it also tries to open the page in your browser.

The dashboard shows the platform build of:

- The engine source into the hosted rules bundle.
- The frontend source into its Vite build output.
- The static files Tableverse serves from that build output.

## Upload from CI

Set the game explicitly for an unlinked non-interactive job:

```bash
TABLEVERSE_GAME_ID=game_123 npx tvk upload
```

`TABLEVERSE_GAME_ID` overrides the saved project link. Authentication must already be available for the same platform API environment.
